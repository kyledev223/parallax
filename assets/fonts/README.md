# Fonts for generated images

Static WOFF files used by `next/og` (OpenGraph and Apple icon images), which can't read the
WOFF2 files that `next/font` serves to browsers.

| --- | --- | --- |
| `InstrumentSerif-Regular.woff` | Instrument Serif 400 | SIL Open Font License 1.1 |
| `JetBrainsMono-Medium.woff` | JetBrains Mono 500 | SIL Open Font License 1.1 |
| `Inter-Regular.woff`, `Inter-Medium.woff` | Inter 400, 500 | SIL Open Font License 1.1 |

Downloaded from [Fontsource](https://fontsource.org) (latin subset). The OFL allows bundling and
redistribution with software; the fonts may not be sold on their own.
